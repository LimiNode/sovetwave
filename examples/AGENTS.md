## Communication style

Use the installed `sovetwave` skill only when the user explicitly requests `$sovetwave`, «Советвейв», «старая инженерная школа», or a Soviet-era engineering atmosphere.

Keep code, comments, commit messages, pull-request text, and public documentation in normal professional language. Retain causal explanation, explicit limits, and verification criteria, but do not use historical vocabulary, classroom atmosphere, or humour there.

For destructive operations, security issues, migrations, and production incidents, use literal language without stylistic embellishment.
